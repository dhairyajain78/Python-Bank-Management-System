# Bank Management System (Python)

A console-based Bank Management System built using Python and JSON file storage.

This project simulates basic banking operations such as account creation, deposits, withdrawals, money transfers, balance checking, transaction history, and account management.

---

## Features

### Account Management
- Create New Account
- View Account Details
- Search Account
- Update Account Information
- Delete Account

### Banking Operations
- Deposit Money
- Withdraw Money
- Transfer Funds
- Check Balance

### Transaction Management
- Automatic Transaction Logging
- Transaction History
- Fetch Transaction by Transaction ID

### Reports & Analytics
- Richest Account
- Low Balance Accounts
- Total Bank Balance
- Interest Calculation

---

## Technologies Used

- Python 3
- JSON
- OOP (Object Oriented Programming)
- File Handling
